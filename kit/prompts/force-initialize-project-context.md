# Force Initialize Project Context Prompt

Use this prompt when the Foundation Kit was just installed or a project is being adopted for the
first time. Apply the `initialize-project-context` workflow.

Do not start feature implementation, execute a feature plan, refactor code, install dependencies
without authorization, modify GitHub settings, release, or deploy.

The skill owns the sources to compare, external-fact research trigger, report structure and local
location, question ordering, project-memory follow-up, and recommended next workflow.
