# Force Project Architecture Plan

Use the `project-architecture-plan` skill to create a project-level architecture and roadmap plan.

The skill owns the project-memory context, blueprint and repository checks, role routing,
docs-first trigger, report structure, plan location, and project-memory follow-up.

Do not implement code, change source files or configuration, install dependencies, commit, push,
directly update project memory, or produce feature-level implementation steps.
